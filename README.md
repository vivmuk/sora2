# Sora 2 Professional Prompt Assistant

A beautiful, modern web application for generating professional-grade cinematic prompts for OpenAI's Sora 2, powered by Venice AI.

## Features

- 🎬 **Professional Prompt Generator** - Transform simple ideas into production-quality Sora 2 prompts
- 📋 **Comprehensive Scaffold** - Complete template covering all cinematic elements
- 💡 **Pro Tips** - Master Sora 2's advanced capabilities
- 🎨 **Elegant Design** - Clean, light theme with smooth animations
- 🔄 **Expandable Sections** - Organized accordion UI for easy navigation
- 🤖 **Venice AI Integration** - Real-time model selection from Venice API

## Sora 2 Capabilities Leveraged

- **Multi-step sequences** with world state tracking
- **Physics-aware** generation (cause & effect, failures, wobbles)
- **Audio synchronization** (dialogue, SFX, ambient sound)
- **Cinematic precision** (duration, resolution, lenses, filtration, grading)

## Deployment

### Netlify (Recommended)

1. Fork this repository
2. Connect to Netlify
3. Deploy automatically with included `netlify.toml` configuration

Or click this button:

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/vivmuk/sora2)

### Manual Deployment

Simply serve the `index.html` file on any static hosting platform.

## Technologies

- Pure HTML/CSS/JavaScript
- Venice AI API
- Font Awesome Icons
- Google Fonts (Playfair Display, Plus Jakarta Sans)

## API Configuration

Update the Venice AI API key in `index.html` to use your own:

```javascript
'Authorization': 'Bearer YOUR_API_KEY_HERE'
```
